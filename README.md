# Roulette

0・00・1〜36の38マスを使ったアメリカンルーレット。赤・黒・数字1つのいずれかと賭け金を選んでスタート。盤と白い玉が回転し、止まった数字と払戻しを表示します。

## 開く

`index.html` をブラウザで開いてください。インストールやビルドは不要です。

## GitHub Pagesで公開

1. GitHubで `Roulette` という公開リポジトリを作成します。
2. このフォルダ内の `index.html`、`style.css`、`roulette.js`、`script.js`、`README.md` をリポジトリの直下にアップロードします。
3. リポジトリの Settings → Pages → Deploy from a branch を選択します。
4. ブランチを `main`、フォルダを `/ (root)` にして Save を押します。
5. Pagesに表示された公開URLを課題の提出先へ送ります。

## 機能

- アメリカンルーレットの数字配列と色
- 減速する回転アニメーション、玉の表示、結果の拡大表示
- 直近10回の履歴（ブラウザ内に保存）とクリア
- 初期2,000コインの所持金とベット、残高保存、ゲームのリセット
- スマートフォン対応、キーボード操作、動きを減らす設定への対応

抽選はブラウザの乱数で各マスを同じ確率で選び、アニメーションの停止位置を合わせています。

## ベットと配当

一度の回転に賭けられるのは1種類のみ。賭け金は所持金以内の正の整数です。

| 賭け先 | 利益の倍率 | 元金込みの払戻し | 的中確率 |
| --- | --- | --- | --- |
| 赤・黒 | 1倍 | 2倍 | 18/38 |
| 数字1つ（0・00も選択可） | 35倍 | 36倍 | 1/38 |

0・00は緑であり、赤・黒は外れとなります。外れた場合、賭け金全額を失います。
回転開始時に賭け金を引いて残高を保存し、的中時に払戻しを加算します。回転中に再読み込みすると、その回の払戻しは行われません。
0コインになるとベットはできません。「最初から」で所持金を2,000に戻し、履歴を消して再開します。
仮想コインのゲームで、購入・換金機能はありません。

配当の参照元： https://www.mgmresorts.com/en/gamesense/guide-to-roulette.html

数字配列の参照元： https://www.pacodeandbulletin.gov/secure/pacode/data/058/chapter617a/chap617atoc.html

金額ボタンは現在の賭け金へ加算します（+100・+500・+1,000）。所持金が上限です。「全額」は所持金を賭け金に設定します。初期の賭け金は0で、金額を選ぶまでスタートできません。
